# Walking sky

Static 360° equirectangular sky generated with the built-in GPT Image tool on 2026-10-24. The panorama adds restrained daytime clouds and atmospheric colour to the walking view. It does not supply lighting or change the campus environment map.

`campus-day.webp` is 2048×1024; `campus-day-mobile.webp` is 1024×512. Longitude edges and spherical poles are blended, and the horizon/lower hemisphere match the campus fog colour `#deddd4`. Optimized files are local and require no external requests. The prompt is recorded in `prompt.txt`.

The local preparation and verification scripts are in `output/sky-atmosphere/`; the original generated image remains in the Codex image directory.
